# Portfolio | Tanishq Parihar

A minimalist, high-performance portfolio website built to showcase engineering problems and solutions.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Font**: Inter & JetBrains Mono

## 🚀 Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:3000](http://localhost:3000) with your browser.

## 📂 Project Structure

- `src/app`: Page layouts and global styles.
- `src/components`: Reusable UI components (Hero, Stats, ProjectCard).
- `src/data`: Resume content and static data.
